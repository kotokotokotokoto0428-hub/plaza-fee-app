# 施設利用料金区分 判定アプリ

ムジカホール・茶霧茶霧ギャラリーの利用条件から、料金区分を判定する静的Webアプリです。

## 起動方法
`index.html` をブラウザで開くだけで動作します。サーバーや追加ライブラリは不要です。

## GitHub Pagesで公開する方法
1. GitHubで新しいPublicリポジトリを作成します（例: `plaza-fee-app`）。
2. このフォルダ内の `index.html` と `README.md` をリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、Branchを `main`、Folderを `/(root)` にして保存します。
5. 数分後に表示されるGitHub PagesのURLから利用できます。

## 判定ルール（提供PDFに基づく）
- STEP2「企業利用（文化利用を除く）」または「主な内容が営業・販売」：入場料にかかわらず営利料金
- 「会員招待のみ（一般の観客は含まない）」：2,001円以上は営利料金、2,000円以下は中段料金
- 「文化利用（企業団体も含む）」または「その他」：2,001円以上は営利料金、501～2,000円は中段料金、500円以下は通常料金
- 入場料は当日券を含む最高料金を使用

## 注意
STEP1で施設選択「その他」は施設共通フローチャートへ進むと記載されていますが、その共通フローチャートは提供PDFに含まれていません。そのため本アプリでは「施設共通フローチャートへ」と案内し、判定を行いません。
実際の料金適用前に、最新の利用規程・施設窓口で確認してください。
